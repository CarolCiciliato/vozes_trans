# Rede Vozes Trans - Roda de Conversa

Este é o projeto completo contendo a interface web e o servidor backend em Node.js com banco de dados SQLite.

## Estrutura do Arquivo
- `server.js`: Servidor backend em Express que gerencia a API e o banco de dados SQLite (`vozes_trans.db`).
- `package.json`: Arquivo de configurações e dependências do projeto.
- `public/index.html`: Arquivo único com a interface web (HTML, CSS e JavaScript), página informativa e formulário de cadastro.

## Como Executar o Projeto

1. Extraia o conteúdo deste arquivo `.zip` para uma pasta no seu computador.
2. Abra o terminal / prompt de comando na pasta do projeto.
3. Instale as dependências executando:
   ```bash
   npm install
   ```
4. Inicie o servidor executando:
   ```bash
   npm start
   ```
5. Abra seu navegador e acesse:
   ```
   http://localhost:3000
   ```
