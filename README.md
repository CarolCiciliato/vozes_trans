# Rede Vozes Trans

Site estático do projeto acadêmico Vozes Trans, desenvolvido por estudantes da Universidade Anhembi Morumbi. A página usa HTML, CSS e JavaScript puros, sem banco de dados ou dependências de execução.

## Executar

Abra `index.html` no navegador. Para servir os arquivos localmente, também é possível executar na pasta do projeto:

```powershell
py -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Arquivos

- `index.html`: estrutura e conteúdo da página.
- `styles.css`: identidade visual e estilos responsivos.
- `script.js`: filtros da galeria, visualizador de imagens, menu mobile e animações.
- `Principal.jpeg` e `Imagem 1.jpeg` a `Imagem 17.jpeg`: cartaz principal e materiais usados no site.

Mantenha os arquivos de imagem na mesma pasta dos arquivos HTML, CSS e JavaScript. Os dados do encontro em destaque seguem o cartaz `Principal.jpeg`.
